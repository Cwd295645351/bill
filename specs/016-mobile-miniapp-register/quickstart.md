# Quickstart: 016-mobile-miniapp-register

## 前提

- 后端可访问；Redis（session / captcha / bindTicket）可用。
- mobile-h5 可打开 `/mobile/`；微信开发者工具可打开 `miniapp/`（已构建 npm）。
- 接口约定见 [contracts/register-api.md](./contracts/register-api.md)；实体见 [data-model.md](./data-model.md)。

## 1. H5 注册 → 登录

1. 浏览器打开移动端入口，确认登录页有「注册」入口。
2. 填写合法用户名、可选昵称、强密码 → 点注册 → 弹窗完成滑块。
3. 期望：提示注册成功并回到登录（**未**直接进入账本页）。
4. 用同一账号密码登录（再过滑块）→ 进入主界面。
5. 负例：弱密码 / 重复用户名 / 关闭滑块 → 不创建账号或明确失败。

耗时目标：网络正常、一次填对，约 3 分钟内完成注册+登录（SC-001）。

## 2. 小程序注册即绑定

1. 使用**未绑定**本系统的微信（或清绑定测试号）打开小程序，进入绑定/注册页。
2. 切换到「注册新账号」，填写合法信息 → 提交 → 滑块。
3. 期望：直接进入主界面；再次打开可静默登录（无滑块、无需再输密码）。
4. 负例：用户名冲突 / 滑块失败 → 仍停留未绑定，无登录态。

耗时目标：约 3 分钟内完成（SC-002）。

## 3. 半失败：账号已建绑定失败（尽量模拟）

若能构造绑定写入失败（如测试桩 / 人为制造 openid 冲突前已插入用户的受控环境）：

- 期望：提示「账号已创建但绑定未完成」类文案；**无**主流程登录态。
- 用同一用户名密码走「绑定已有账号」→ 成功进入。

无法稳定复现时，至少代码评审确认 `wxRegister` 绑定失败分支不发 JWT、不删用户。

## 4. 回归：已有路径

| 路径 | 期望 |
|------|------|
| H5 登录（已有账号） | 与改前一致 |
| 小程序绑定已有账号 | 与改前一致 |
| 小程序已绑定静默登录 | 无注册强推、无滑块 |
| PC 注册 / 登录 + 滑块 | 行为不变 |
