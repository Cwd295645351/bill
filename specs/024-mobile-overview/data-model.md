# 数据模型：移动端收支概览

本特性**不新建表、不改列**。数量和归属继续读现有 `bill_overview_rules` 与 `bill_overview_rule_years`。手机只读，任何概览操作都不得插入或更新这些行。

记账、成员、类型仍用现有表。记账日期仍是当天 00:00:00。查询开始取当天 00:00:00，结束取当天 23:59:59.999，从而包含结束日。

## 统计区间

| 字段 | 说明 |
|------|------|
| beginDate | `YYYY-MM-DD`，含当日 |
| endDate | `YYYY-MM-DD`，含当日结束（23:59:59.999） |
| dimension | 仅客户端：「月」或「年」。不上传 |
| labelYear / labelMonth | 仅客户端。翻月、翻年或点选年月时，把两端重置为该自然月或自然年的首尾日。只改一端时，标题保持不变 |

校验：开始不得晚于结束。合法修改后立即重新请求。切换账本后，客户端回到当前自然月和「月」，不保留上一账本的日期。

## 收支汇总

来自区间内未删除记账，与数量规则无关。

| 字段 | 说明 |
|------|------|
| totalCost | 支出合计 |
| investCost | 支出类型「基金」（id `1015`）合计 |
| consumptionCost | 总支出减总投资，保留到分 |
| totalIncome | 收入合计 |

没有记账时四项都是 0。

## 成员收入

当前成员里，区间内归属到该成员的收入合计。公共收入和已离开成员的收入不单列。金额为 0 的成员不出现。展示文案为「成员名收入」，不含记账人前缀。顺序与账本成员加入顺序一致。全空时界面说明这段时间没有收入。

## 数量规则配置（只读）

某条仍启用的数量规则，在某一个自然年已保存的数量和归属。手机响应**不得**包含数量、单价、归属或规则名称输入。停用或已删除的规则不参与。某年没有配置时，该年数量按 0。指定支出类型规则没有输入，仍在各年分摊里自动扣减。

## 结算建议

| 字段 | 说明 |
|------|------|
| lines | 一组文案。未传数量时与电脑端同一区间的句子一致，包括跨年。跨年是各年净额相加后的一组句子 |

句子只使用现有读法：`无需分账`、`双方结清，无需转账`、`各方结清，无需转账`，或若干条 `某成员 → 某成员 转 x.xx 元`。两人有差额时只有一条转账；三人及以上逐条列出。

## 支出分类项

某一视图（全部，或一名当前成员）下的一类支出。

| 字段 | 说明 |
|------|------|
| costTypeId | 点开明细用 |
| name | 分类名 |
| money | 「全部」为记账原金额；成员为各年应承担份额之和 |
| count | 该视图下可点开的原始记账笔数 |
| percent | 两位小数字符串，同一列表相加为 100.00。最后一项用 100 减去其余项 |

金额为 0 的分类不出现。只有一名当前成员时，不提供成员视图，只保留「全部」。

## 分类明细

点开后的一条原始支出。

| 字段 | 说明 |
|------|------|
| date | `YYYY-MM-DD` |
| payerName | 记账人，不可在本页修改 |
| belongName | 归属展示：一名成员、多名成员或「全部」 |
| money | 记账原金额，不是分摊份额 |
| remark | 备注，可空 |

成员筛选与分类笔数使用同一条件。

## 可选年份

| 字段 | 说明 |
|------|------|
| minYear | 已有记账最早年与当前年中的较早者 |
| maxYear | 已有记账最晚年与当前年之后 10 年中的较晚者 |

没有记账时，最小为当前年，最大为当前年之后 10 年。选择未来年且没有数据时，按空区间处理。
