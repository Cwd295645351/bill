# Feature Specification: 排除固定资产

**Feature Branch**: `012-exclude-fixed-assets`

**Created**: 2026-11-04

**Status**: Draft

**Input**: User description: "PC 端家庭资产卡片新增「排除固定资产」按钮；开启后净资产和总资产都扣除固定资产金额。总负债不变。默认关闭。不改已归档 specs/001–009。"

## Background

电脑网页「资产 → 总览」左侧「家庭资产」卡片展示净资产、总资产、总负债。部分用户希望临时按「不含固定资产」查看家庭净资产与总资产，以便评估流动/投资类资产水平。本能力仅影响该卡片上的展示数字，不改变登记数据、饼图、分组表及其他页签。

## User Scenarios & Testing *(mandatory)*

电脑网页进入账本后的「资产 → 总览」。微信小程序、移动端 H5 不新增本开关。

### User Story 1 - 一键排除固定资产看净资产与总资产 (Priority: P1)

用户在家庭资产卡片上看到「排除固定资产」控件。默认关闭，数字与现状一致。开启后，净资产与总资产均减去当前固定资产合计，总负债不变；再次关闭则恢复原数字。开启态视觉上与关闭态可区分。

**Why this priority**: 这是本需求的唯一主路径。

**Independent Test**: 打开总览，记下净资产/总资产/总负债与固定资产分组金额；开启「排除固定资产」后核对新净资产=原净资产−固定资产、新总资产=原总资产−固定资产、总负债不变；关闭后数字回到开启前。

**Acceptance Scenarios**:

1. **Given** 总览家庭资产卡片且固定资产合计大于 0，**When** 开启「排除固定资产」，**Then** 总资产减少该固定资产合计，净资产同步减少相同金额，总负债不变。
2. **Given** 开关已开启，**When** 再次关闭，**Then** 净资产与总资产恢复为开启前数值。
3. **Given** 开关处于开启态，**When** 查看控件样式，**Then** 开启态与关闭态明显可辨（与现有「成员」「汇率」同类按钮的选中态协调）。

---

### User Story 2 - 无固定资产时开关不改数字 (Priority: P2)

账本没有固定资产、或固定资产合计为 0 时，开启开关后净资产与总资产保持不变；总负债仍不变。

**Why this priority**: 边界路径，避免出现「扣了却看不出变化」时的误导或 NaN。

**Independent Test**: 在无固定资产（或金额为 0）的账本/成员筛选下开启开关，三数不变。

**Acceptance Scenarios**:

1. **Given** 固定资产合计为 0 或不存在，**When** 开启「排除固定资产」，**Then** 净资产、总资产、总负债均与关闭时相同。

---

### Edge Cases

- 固定资产为 null/缺失时按 0 处理，开启后数字不变。
- 开启后净资产可为负（总资产小于负债时），按实数展示，不额外钳制为 0。
- 切换成员筛选或刷新总览后：开关保持当前会话选择；展示数字按最新合计重算。
- 右侧「较上次盘点」、四笔钱饼图、资产类型饼图、下方分组表不受本开关影响。
- 汇率说明文案不因本开关改写。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 电脑端家庭资产卡片必须提供「排除固定资产」可切换控件；默认关闭。
- **FR-002**: 开启时，卡片展示的总资产必须等于关闭时总资产减去当前固定资产合计。
- **FR-003**: 开启时，卡片展示的净资产必须等于关闭时净资产减去当前固定资产合计（等价于开启后总资产减总负债，须与现有净资产定义一致）。
- **FR-004**: 开启或关闭时，卡片展示的总负债必须不变。
- **FR-005**: 固定资产合计为 0 或缺失时，开启后净资产与总资产展示结果与关闭时相同。
- **FR-006**: 开启态必须有明显视觉反馈，样式与卡片上「成员」「汇率」类按钮协调。
- **FR-007**: 本开关仅影响家庭资产卡片上的净资产与总资产展示；不得改写后端数据、不得改变其他图表/表格口径。
- **FR-008**: 不得修改 `specs/` 下已归档目录（含 001–011）的既有正文；本能力规格仅落在本目录。

### Key Entities

- **家庭资产卡片展示值**: 净资产、总资产、总负债（人民币折算后）。
- **固定资产合计**: 当前成员筛选下「固定资产」类型资产的折人民币合计。
- **排除固定资产开关**: 会话内布尔状态，默认 false。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在 1 次点击内切换排除/不排除，并立即看到净资产与总资产变化（或确认无变化）。
- **SC-002**: 对任意有固定资产的样本，开启后「总资产减少额」与「净资产减少额」均等于固定资产合计（浮点容差除外）。
- **SC-003**: 总负债在开关切换前后保持一致。
- **SC-004**: 代码审查中无对已归档 specs（001–011）正文的修改。

## Assumptions

- 固定资产合计取自现有总览数据中「固定资产」分类金额，无需新增接口字段。
- 开关状态仅保存在当前页面会话，不做跨刷新持久化（项目内同类开关无既有偏好存储惯例）。
- 仅 PC 前端总览卡片；小程序与 mobile-h5 本阶段不做。
- 「登记资产 / 成员 / 汇率」行为与文案不变。

## Out of Scope

- 修改后端汇总 API 或数据库口径。
- 让饼图、分组表、趋势、月历同步排除固定资产。
- 修订已归档 specs（001–011）正文。
- localStorage 持久化（除非后续单独提出）。
