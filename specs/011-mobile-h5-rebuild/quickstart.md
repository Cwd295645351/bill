# Quickstart: 011-mobile-h5-rebuild

本指南用于**实现完成后**的验收走查。plan 阶段不执行编码；下列命令在 `tasks` / `implement` 落地后使用。

## 前提

- 本机可跑现网 `server/`（MySQL/Redis/环境变量按 `deploy` 与 `server/.env`）。
- 已有测试账号（**不能**靠 H5 注册；用 PC 注册或库内已有用户）。
- `mobile-h5` 已按 plan 创建并可 `npm run dev` / `build`。

## 本地联调（示意）

```text
# 终端 1：API
cd server && npm run dev   # 或项目惯用启动方式

# 终端 2：H5
cd mobile-h5 && npm install && npm run dev
```

开发服务器将 `/api` 代理到本机 API（对齐 `frontend` 代理思路）。生产验证则 build 后放入 Nginx `.../bill/mobile/`，访问 `https://<host>/mobile/`。

## 验收场景（对照 spec）

1. **登录成功**：有效账号密码 → 进入主界面并见账本 Tab；错误密码 → 提示且不进业务页。
2. **无注册**：登录页无注册入口；直接访问「注册」类路由（若误加）应不存在或不可用。
3. **无微信绑定**：无绑定页；网络面板主路径无 `/wxLogin`、`/wxBind`。
4. **账本 → 记一笔**：打开账本详情 → 记一笔支出 → 账单中可见；收入仅单成员归属。
5. **权限**：非创建者无法改删他人明细（与 API 错误一致）。
6. **搜索 / 改自己的账**：关键字命中；改金额或备注后列表更新；无匹配空状态。
7. **我的 / 退出**：展示身份 → 退出 → 再进账本需登录。
8. **加入账本**：有效邀请成功；无效邀请失败说明。
9. **部署合同**：`/mobile/` 可打开 H5；`/mobile/` 仍 404，且不跳转到 `/mobile/`。
10. **归档未动**：`git diff specs/001-010` 无内容变更。

- 同账号 H5 与 PC 对抽样账本记录条数/权限一致。
