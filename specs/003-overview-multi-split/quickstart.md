# Quickstart: 概览多人分账

用这条路径验收 [spec.md](./spec.md)。接口以 [contracts/overview-settlement.md](./contracts/overview-settlement.md) 为准，计算对象以 [data-model.md](./data-model.md) 为准。这里不写实现代码。

## 准备

1. 启动现有记账服务和电脑端。不需要新的环境变量，也不需要新表。
2. 准备四个账本，或在验收时改成员：两人、三人、四人、一人。成员姓名用甲、乙、丙、丁，方便对文案。
3. 电脑端打开概览。默认区间会含当年其它账，验收每一例之前把开始和结束时间收成只盖住下面这些记账的区间，再点「查询」。
4. 手机网页和小程序只做对照，不要出现新的分账入口。

金额都用「元」。下面每一例查询一次，并看结算文案、个人支出结构和下钻。

## 1. 三人平摊一笔公共支出

成员甲、乙、丙，有效收入相同（可以都不记收入）。只记一笔：甲支付 300，归属「全部」。

预期：每人承担 100。文案为「乙 → 甲 转 100.00 元」和「丙 → 甲 转 100.00 元」。不是只在甲、乙之间结 150。甲的支出结构里这笔是 100，不是 300。「全部」里仍是 300。

## 2. 代付再加一笔公共聚餐

同一三人账本，有效收入相同。

- 甲支付 300，归属乙。
- 丙支付 90，归属「全部」。

预期：乙承担 330，甲、丙各承担聚餐里的 30。文案为「乙 → 甲 转 270.00 元」和「乙 → 丙 转 60.00 元」。甲的结构里没有那件衣服，有聚餐份额。乙的结构里两类都有。

## 3. 收入不同的三人

甲、乙、丙的归属收入分别为 6000、3000、3000，都归属本人，没有规则。甲支付 1200，归属「全部」。

预期：承担额 600、300、300。乙、丙各转 300 给甲。

## 4. 四人平摊

四名成员，有效收入相同。其中一人支付 100，归属「全部」。

预期：每人 25。另外三人各转 25 给付款人。转账不超过 3 笔。四个人的支出结构都能看到，不只有前两名。

## 5. 两人回归

成员只有甲、乙。

1. 有效收入相同。甲付 200，归属「全部」。预期：各 100，「乙 → 甲 转 100.00 元」。
2. 甲付 300，归属乙。预期：「乙 → 甲 转 300.00 元」。
3. 甲的归属收入 6000，乙 4000。甲付 1000，归属「全部」。预期：甲承担 600，乙承担 400，「乙 → 甲 转 400.00 元」。
4. 两人有效收入都是 0。甲付 200，归属「全部」。预期：仍按 1:1，乙转甲 100。
5. 没有支出，或双方净额为 0。预期：「双方结清，无需转账」，没有 0 元那一行。
6. 甲的归属收入 8000；数量规则数量 10、单价 200、归属人选甲。乙的归属收入 10000，另有一笔归属乙的 1000 元被已启用的指定支出类型规则扣掉。甲付 15000，归属「全部」。预期：有效收入 6000 与 9000，承担 6000 与 9000，「乙 → 甲 转 9000.00 元」。

例 1 的那笔若把报销进度改成「已报销」「待报销」或「已提交」，应退仍是乙转甲 100，与「无需报销」相同。

## 6. 不能整除

三人，有效收入相同。一笔公共支出 100。

预期：按结算结果中成员顺序，前两人为 33.33，最后一名为 33.34，合计 100.00。最后一名的饼图上该类为 33.34。点开明细时，金额列是 100.00，没有分账后的金额。

## 7. 不点查询就不更新

先查出一组建议。只改结束时间或数量，不点「查询」。

预期：文案和支出结构仍是上一次的。再点「查询」才变。

## 8. 一名成员

账本只有一名成员，有一些归属「全部」或归属本人的支出。

预期：只有「全部」支出结构。文案为「无需分账」，没有转账对象。

## 9. 不该变化的地方

1. 同一区间的总支出、总投资、总消费、总收入与改这个功能之前的汇总一致。总消费仍是总支出减去「基金」。基金支出仍然进分账。
2. 近三年趋势的年份、各类型、总消费、总支出不变，不按人拆开。
3. 左侧按记账人、归属人展开的明细行保持进入本功能时的样子。
4. 手机网页和小程序的记账、流水、账本内汇总数字不变，没有结算建议。
5. 类型管理里的概览规则仍只有账本创建者能改，仍然是数量乘单价或指定支出类型，查询框不会为每个成员各出现一个数量。
6. 不是该账本成员的人调用结算接口，看不到金额。

## 10. 手册

打开用户手册中概览和「三人及以上」的段落。

预期：不再写「只按成员列表前两名计算」。能找到至少一个三人例子，读法和页面上的「谁转给谁」一致。两人的读法仍在。
