# 契约：账本权限

**功能分支**: `022-backend-domain-modules` | **日期**: 2026-11-17

数据关系见 [data-model.md](../data-model.md)。这里只规定一次请求如何被接受或拒绝。

## 判断顺序

1. 未登录或登录过期：仍按现在的鉴权失败，看不到账本数据。
2. 操作针对某一个已有账本时，先确认登录者是 `bill_users` 中的成员。不是成员则失败，响应不得包含该账本的明细或金额。
3. 是成员之后，再按动作检查创建者或记账人。
4. 只有资产、盘点或资产成员的编号时，先反查所属账本，再执行第 2 步。反查失败按找不到资源处理，不得借此读到别的账本。

下列动作不是「查看或修改某一个已有账本」，不得按非成员拒绝：

- 注册、登录、滑块、修改自己的资料和密码
- 新建账本
- 查看自己已加入的账本列表
- 凭有效且未过期的邀请加入

## 新补上的非成员拒绝

这些路径今天只确认登录。本次必须在读数据或写入之前拒绝非成员，说明为「不是该账本成员」：

| 方法 | 地址 | 动作 |
|------|------|------|
| POST | `/api/v1/transaction/list` | 流水列表 |
| GET | `/api/v1/transaction/currentMonthCost` | 当月支出 |
| POST | `/api/v1/transaction/export` | 导出 |
| POST | `/api/v1/transaction/const` | 导入 |
| POST | `/api/v1/transaction/` | 新增 |
| POST | `/api/v1/transaction/batch` | 批量新增 |
| PUT | `/api/v1/transaction/` | 编辑（非成员时；成员见下） |
| DELETE | `/api/v1/transaction/` | 删除（非成员时；成员见下） |
| GET | `/api/v1/overview/balance` | 区间收支 |
| GET | `/api/v1/overview/threeYearCost` | 近三年支出 |
| PUT | `/api/v1/bill/` | 改名（非成员时；成员见下） |

实现时若发现还有只校验登录的账本操作，同样在成员判断处拒绝，说明也用「不是该账本成员」。不得只补上表而留下另一个入口。

## 已经在用的说明（保持原文）

| 场景 | 说明 |
|------|------|
| 是成员但不是创建者，修改账本名称 | 只有账本创建者才能修改账本名称 |
| 非创建者管理类型 | 只有账本创建者才能管理类型 |
| 非创建者管理概览规则 | 只有账本创建者才能管理概览规则 |
| 预算或计划，调用者不是成员 | 该用户并未加入此账本 |
| 账本详情，调用者不是成员 | 找不到账本 |
| 删除账本，但不是创建者 | 找不到该账本或您非该账本的创建者 |
| 分账，调用者不是成员 | 不是该账本成员 |
| 家庭资产，调用者不是成员 | 无权查看该账本 |
| 智能解析指定了别人的账本 | 无权访问该账本 |
| 上传照片时不是成员 | 未找到账本 |
| 退出时并未加入 | 您并未加入该账本 |
| 非创建者移除成员 | 仅账本创建者可移除成员 |
| 创建者退出 | 创建者不能退出账本 |
| 是成员但不是记账人，编辑明细 | 只能编辑自己记的账单 |
| 是成员但不是记账人，删除明细 | 只能删除自己记的账单 |

类型模块里已经使用的「无权访问该账本数据」「无权管理该账本数据」也保持不变。

## 成员可以做、创建者才可以做

- 成员：流水、概览、分账、当年预算、计划、家庭资产，以及记一笔。
- 仅创建者：分享邀请、修改名称、删除账本、移除成员、管理类型和概览规则。
- 仅记账人：编辑或删除自己的明细，增删自己明细上的照片。同一账本的其他成员仍可查看照片。

智能解析未配置、超过当日额度、解析成功的说明保持现在的句子。未真正调用外部解析的失败仍不计入当日次数。
