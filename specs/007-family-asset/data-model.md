# Data Model: 家庭资产

不新增表，不新增列。资产成员、资产、盘点沿用现有 `members`、`assets`、`asset_records`。金额是最多两位小数的数。删除都是隐藏（`is_del`），不做物理删除。

## 资产成员（members）

某个账本下的人名，和记账成员 `bill_users` 不是同一份名单。

| 字段 | 说明 |
|------|------|
| id | 成员 id |
| bill_id | 所属账本 |
| name | 名字。新增和改名时不能为空 |
| is_del | 隐藏后为真。名单不再返回。名下资产不删、不改归属 |

关系：一个账本有多名资产成员。一笔资产只属于一名资产成员。

## 资产（assets）

| 字段 | 说明 |
|------|------|
| id | 资产 id |
| bill_id | 所属账本。必填 |
| member_id | 资产成员。必须是本账本未隐藏的成员 |
| name | 名称。必填 |
| type | 资产类型，见下表。必填 |
| four_money_type | 四笔钱，见下表。资产类型不是负债时必填，且与资产类型独立。类型为负债时为空字符串，表示不归入四笔钱。列本身仍不允许数据库空值 |
| is_debt | 负债标记。类型为 `debt` 时为真，否则为假。创建、编辑和存量回填都按类型写入 |
| latest_amount | 当前金额，大于 0。等于未隐藏盘点里日期最新的一条 |
| insurance_category | 险种。仅四笔钱为保险时保留；否则清空 |
| annual_premium | 年交保费。仅四笔钱为保险时保留；否则清空 |
| last_updated_date | 最近盘点日期，取最新一条盘点的日期 |
| is_del | 隐藏后，该资产及其盘点不再出现在列表和统计中 |

### 资产类型

| 存储值 | 页面名称 | 计入 |
|--------|----------|------|
| living | 流动资金 | 总资产 |
| steady | 固定资产 | 总资产 |
| longterm | 投资理财 | 总资产 |
| receivable | 应收款 | 总资产 |
| debt | 负债 | 总负债，不计入总资产 |

### 四笔钱

| 存储值 | 页面名称 |
|--------|----------|
| living | 活钱 |
| steady | 稳健 |
| longterm | 长期 |
| insurance | 保险 |

四笔钱只汇总这一列有取值的非负债资产。类型为负债时该列为空，不进入任何四笔钱卡片。

未填险种的保险，汇总时归入「其他」。

## 盘点（asset_records）

| 字段 | 说明 |
|------|------|
| id | 盘点 id |
| asset_id | 所属资产 |
| amount | 金额，大于 0 |
| date | 日期的时间戳。页面按自然日显示和选择 |
| is_del | 隐藏后不参与当前金额和统计 |

规则：

- 登记资产成功时自动写一条，金额为当前金额，日期为登记当时。
- 编辑资产时，只有 `latest_amount` 的数值变了才新增一条。
- 用户可以改任意一条的金额和自然日。保存更新这一条，不另增。
- 只剩一条未隐藏盘点时不能再隐藏。
- 新增、修改、隐藏之后，用剩余盘点重算资产的当前金额和最近日期。
- 同一资产、同一自然日有多条时，后保存的那条在该自然日内的时间戳更晚，按日期倒序时排在前面。页面仍显示同一个自然日。

## 状态变化

```text
登记资产
  → 写入资产（按类型设置负债标记）
  → 写入第一条盘点
  → 当前金额 = 该盘点

编辑资产且金额未变
  → 更新名称、成员、类型、四笔钱、保险信息、负债标记
  → 盘点条数不变

编辑资产且金额已变
  → 同上，并新增一条盘点
  → 当前金额 = 新金额

追加或修改盘点
  → 按日期最新的一条重算当前金额
  → 若改的是较早日期，当前金额可以不变

隐藏盘点（多于一条时）
  → 按剩余盘点重算当前金额

隐藏资产
  → 资产和它的盘点从列表、统计中消失

隐藏资产成员
  → 名单中消失
  → 名下资产仍在，家庭合计不变
```

## 统计口径

这些数不另存一张表，读取时计算。

- 总资产 = 未隐藏、非负债资产的当前金额之和。
- 总负债 = 未隐藏、负债资产的当前金额之和。
- 净资产 = 总资产 − 总负债。
- 总览可以打开「排除固定资产」。打开后，当时展示的净资产、总资产、总资产较上月末、类型对比和分组都不含固定资产；总负债不变。关闭后恢复上面的口径。占资产按当时的总资产重算。
- 总览每个类型组内再按成员小计。
- 上月末对比日 = 上一个自然月的最后一天。总资产变化 = 当前非负债合计 − 该日非负债合计。
- 月历某月某笔资产 = 该月最后一刻之前、日期最新的一条未隐藏盘点。没有这样的盘点时，该月不编造 0。
- 较年初 = 所看月份金额 − 该年 1 月金额。1 月没有盘点时按 0。所看月份没有金额时，较年初为空。
- 今年尚未到来的月份不返回金额。
- 构成：净资产与负债进入总资产；总资产只拆到四类非负债，再拆到每一笔。负债不在右侧再出现。色带按实际金额绘制。
- 趋势全部口径：流动资金、投资理财、固定资产、应收款向上堆叠；负债取总负债的相反数，画在零轴下方。

## 存量回填

不改表。上线时执行一次幂等更新：`type = debt` 且 `is_debt` 仍为假的未隐藏资产，把 `is_debt` 改为真。重复执行结果相同。代码回滚后若要恢复旧口径，需把这些行的 `is_debt` 改回假；那会重新把负债算进总资产，只在明确放弃本次口径时才做。

## 不在本次模型里的事

- 不把资产成员同步成记账成员。
- 不增加资产照片。
- 不把资产金额写入记账、预算或概览分账。
