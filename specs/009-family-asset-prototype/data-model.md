# Data Model: 按原型补齐家庭资产

金额在库里仍用元，计算分摊时沿用概览的「分」整数。展示人民币时才乘汇率。

## 资产 `assets`

在现有列上增加和放宽：

| 字段 | 规则 |
|------|------|
| `currency` | `CNY`、`HKD`、`USD`。新建默认 `CNY`。已有行回填 `CNY`。创建后不可改 |
| `latest_amount` | 仍是原币。当前金额来自日期最新的未删除盘点 |
| `four_money_type` | 负债必须为空。非负债仍是活钱、稳健、长期、保险之一 |
| `insurance_category`、`annual_premium` | 只有四笔钱为保险时保留。年交保费留空或是不小于 0 的数字。离开保险时清空 |

类型与负债标记的对应关系不变：只有类型为负债时 `is_debt` 为真。

## 盘点 `asset_records`

不改列。`amount` 是原币，必须大于 0。`date` 仍是时间戳，按自然日比较。同一天多条时，当前金额和「截至某日」都取最后保存的那条。只剩一条时拒绝删除。

## 汇率 `bill_exchange_rates`

一个账本一行。

| 字段 | 规则 |
|------|------|
| `bill_id` | 主键，对应账本 |
| `hkd_rate` | 1 港币折合多少人民币，必须大于 0 |
| `usd_rate` | 1 美元折合多少人民币，必须大于 0 |

没有这一行时，读取返回大于 0 的初始值，并标明尚未保存。保存后才插入或更新。改汇率不写盘点。

折算：人民币乘 1，港币乘 `hkd_rate`，美元乘 `usd_rate`。

## 养老计划 `asset_retire_plans`

| 字段 | 规则 |
|------|------|
| `id` | 主键 |
| `bill_id` | 账本 |
| `member_id` | 空表示「全部」。否则是未隐藏的资产成员。同一账本、同一成员范围只有一行 |
| `amount` | 人民币目标，必须大于 0 |
| `start_month` | `YYYY-MM`，必填，不得晚于本月 |
| `target_month` | `YYYY-MM`，可空。有值时必须晚于本月 |

隐藏资产成员不删除这一行，只是筛选里不再打开它。「全部」那一行不受影响。

## 对账用到、但不由本次改写的数据

- `transactions`：该年未删除记账。收入 `type = 2` 只能归属一名成员。支出 `type = 1` 可以是「全部」、一名或多名成员。
- `bill_users`：记账成员，按 `id` 升序，和概览分账的成员顺序相同。
- `bill_overview_rules`：只读已启用规则。`quantity` 用请求里的数量和归属人；`cost_type` 扣对应支出类型。
- `members`：资产成员。和记账成员只按姓名精确对应，不新增外键。

## 关系

- 一个账本有一套汇率、多名资产成员、多笔资产、零条或一条「全部」养老计划。
- 一名资产成员有多笔资产，以及至多一条自己的养老计划。
- 一笔资产有多条原币盘点。
- 对账不产生新的持久化记录。

## 校验与状态

- 创建资产：币种三选一，金额大于 0。非负债必须有四笔钱。保险的年交保费若填，则不小于 0。成功后自动有一条当天盘点。
- 编辑资产：忽略或拒绝币种变化。金额数值未变不新增盘点。改成负债时清空四笔钱、险种和年交保费。
- 追加或修改盘点：金额大于 0，日期必填。之后按日期最新的一条重算 `latest_amount`。
- 保存汇率：两个汇率都大于 0，否则整次失败，原值不变。
- 保存养老计划：目标金额大于 0，开始月份不晚于本月，目标月份为空或晚于本月。失败时不写。

## 回滚

先停用新页面入口，再删 `bill_exchange_rates`、`asset_retire_plans`，并去掉 `assets.currency`。已有盘点仍是当时录入的数；上线前它们都按人民币理解，回填的币种是 `CNY`，删列前不影响原币含义。`four_money_type` 若已改为可空，回滚时先把负债行填回上线前的值，再恢复非空约束。
