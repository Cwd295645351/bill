# Contract: 家庭资产

电脑网页进入账本后使用。微信小程序不调用。前缀保持 `/api/v1/asset`。不新增路径，不删除已有字段。

登录方式与其它 `/api/v1` 接口相同。除此以外，每条接口都要求当前用户是目标账本的成员。不是成员时返回失败，文案说明无权查看该账本，响应里不带资产数据。盘点请求若只有资产 id，服务端用该资产的账本做成员检查。

金额是大于 0 的数。日期在请求和展示中按自然日理解，存储仍是时间戳。

类型和四笔钱的取值见 [data-model.md](../data-model.md)。页面显示中文名，请求使用存储值。

## 行为更正

下列改变的是今天错误的结果。仓库里没有已发布的电脑页面或小程序页面依赖旧结果。

| 位置 | 更正后 |
|------|--------|
| 创建、编辑资产 | 按类型写入负债标记。类型为负债时不把险种要求变成必填 |
| 编辑资产 | 仅当前金额数值变化时新增盘点 |
| 新增、修改、删除盘点 | 当前金额改为日期最新的一条，而不是无条件改成刚提交的那条 |
| 四笔钱不是保险 | 清空险种和年交保费 |
| `GET /four-money`、`/sankey`、`/monthly-report` | 账本必填。缺少时失败，文案为「账本id不能为空」 |
| `GET /overview` | 总资产变化只比较非负债合计 |
| `GET /sankey` | 类型节点为中文；固定资产不使用「固定资金」；负债只出现在左侧 |
| `GET /monthly-report` | 分类按中文名累加；尚未到来或没有盘点的月份为 `null`，不是 0 |

存量负债标记的回填见 [data-model.md](../data-model.md)，不是新接口。

## 成员

### GET /api/v1/asset/members?billId=

返回该账本未隐藏的资产成员。已隐藏的不返回。

### POST /api/v1/asset/member

`billId`、`name` 必填。创建后出现在名单中。不要求该名字对应登录账号。

### PUT /api/v1/asset/member

`id`、`name` 必填。改名后，仍引用该成员的资产显示新名字。

### DELETE /api/v1/asset/member?id=

隐藏该成员。不隐藏、不改写其名下资产。家庭合计不变。

## 资产

### GET /api/v1/asset/list?billId=&memberId=&type=&fourMoneyType=

`billId` 必填。其余可选。只返回未隐藏资产。可按成员、资产类型、四笔钱筛选。

### GET /api/v1/asset/list-stats?billId=&memberId=

供总览列表。`billId` 必填。`memberId` 为空表示整个账本。

返回总资产、总负债、净资产，以及按类型分组的合计、变化额、变化率、占对应总额的比例。组变化额只累加有上一次盘点的资产；该组全部没有上一次盘点时变化额为空，不返回 0。每笔资产包含成员名、四笔钱、当前金额、上一次盘点金额、变化额、变化率和占本组比例。占本组是该笔占所属类型合计的比例。只有一条盘点时，变化率为空，不返回 0 冒充变化率。

总资产不含负债。指定成员时，合计和分组只含该成员。

### POST /api/v1/asset/

创建。必填：`name`、`billId`、`memberId`、`type`、`latestAmount`。`type` 不是 `debt` 时，`fourMoneyType` 也必填。`type` 为 `debt` 时，`fourMoneyType` 为空字符串，不要求四笔钱。金额必须大于 0。缺任一项或金额不合法时失败，不产生资产，也不产生盘点。

成功时写入负债标记，并自动写一条盘点，日期为登记当时，金额为当前金额。四笔钱为 `insurance` 时可以带 `insuranceCategory`、`annualPremium`。不是保险时这两项不保存。

### PUT /api/v1/asset/

更新名称、成员、类型、四笔钱、金额和保险信息。负债标记随类型更新。类型改为负债时，`fourMoneyType` 改为空字符串。金额数值未变时，盘点条数不变。金额变了才新增盘点，当前金额变为新金额。四笔钱改为非保险或类型改为负债时，清空险种和年交保费。

### DELETE /api/v1/asset/?id=

隐藏资产及其盘点。之后列表和各项统计都不再包含它们。

## 盘点

### GET /api/v1/asset/records?assetId=&startDate=&endDate=

`assetId` 必填。给出起止日期时，只返回落在该自然日范围内的未隐藏盘点，按日期从新到旧。

### POST /api/v1/asset/record

`assetId`、`amount`、`date` 必填。金额必须大于 0。成功后按日期最新的一条重算当前金额。提交一条更早的日期时，当前金额保持为更新的那条。

### PUT /api/v1/asset/record

`id`、`assetId`、`amount`、`date` 必填。更新这一条，不另增。然后按同样规则重算当前金额。未提交成功时原记录不变。

### DELETE /api/v1/asset/record?id=

未隐藏盘点只剩一条时失败，文案说明只剩一条时不能删除。多于一条时隐藏这一条，并按剩余记录重算当前金额。

## 统计

### GET /api/v1/asset/overview?billId=&memberId=

`billId` 必填。没有资产时，总资产、总负债、净资产、总资产变化均为 0。

返回当前净资产、总资产、总负债、对比日（上一个自然月的最后一天，`YYYY-MM-DD`）、总资产变化，以及各类型的当前值、上月末值、变化额。总资产变化不得把负债加进被减数或减数。

### GET /api/v1/asset/four-money?billId=&memberId=

`billId` 必填。返回活钱、稳健、长期、保险的金额、笔数和明细。没有四笔钱取值的资产（包括保存为负债的资产）不进入任何卡片。保险另有年交保费合计；没有险种的计入「其他」。电脑端为活钱、稳健、长期计算占这三类总额的比例，三者之和为 100%，保险不计入；明细再按成员小计。比例不另设接口字段。

### GET /api/v1/asset/sankey?billId=&memberId=

`billId` 必填。返回节点和连线：

- 左侧：净资产、负债 → 总资产。负债节点带上负债明细的名称；这些负债属于同一成员时带上该成员名。
- 右侧：总资产 → 流动资金、固定资产、投资理财、应收款 → 每一笔非负债资产。
- 资产节点带成员名，供「全部」时画归属标记。
- 金额为 0 的连线不出现。
- 连线的 `value` 是实际金额。电脑端用 ECharts 桑基图按该金额画色带，不按开方。

比例和隐藏金额不另设参数，电脑端用这些金额切换标注。比例的分母是总资产。

### GET /api/v1/asset/monthly-report?billId=&year=&memberId=

`billId` 必填。`year` 缺省为今年。

返回流动资金、投资理财、固定资产、应收款、总资产、总负债、总净资产。每一类包含：

- `monthlyData`：长度 12。有盘点的月份是金额；没有盘点，或今年尚未到来的月份，是 `null`。
- `current`：今年为本月金额，过去的年份为 12 月金额。
- `yearChange`：所看月份相对该年 1 月的变化，页面称「较年初」。1 月为 `null` 时按 0 相减。所看月份没有金额时变化为空。月度序列中没有盘点的月份仍是 `null`，不得填 0。
- `lastUpdate`：该分类最后一次盘点的自然日。没有则为空。

某月总资产等于该月非负债之和，总净资产等于总资产减总负债。电脑端用这份结果画月历，并按年拼接成趋势，不再请求别的统计路径。
