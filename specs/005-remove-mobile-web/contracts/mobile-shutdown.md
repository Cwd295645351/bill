# Contract: 手机网页关停

电脑网页 `/pc/` 与 `/api/v1` 不在本次变更内。这里只规定被关掉的静态入口。

## 静态入口

下列 URL 都不再由本站点提供正文。响应使用 Nginx 默认 404，不自定义 `error_page`，不返回 301 或 302。

| 请求 | 结果 |
|------|------|
| `GET /mobile` | 404，不跳转到 `/mobile/` 或 `/pc/` |
| `GET /mobile/` | 404，正文不是记账页面，也不是迁移说明 |
| `GET /mobile/index.html` | 404 |
| `GET /mobile/` 下任意静态资源 | 404 |
| 带 hash 的旧链接，例如 `/mobile/#/某账本` | 浏览器只向服务器请求 `/mobile/` 或 `/mobile/index.html`，结果同上。hash 不会让服务器返回账本内容 |

响应头不得把用户带到电脑网页或小程序。响应正文不得出现账本名称、金额、流水或「请改用小程序」一类产品文案。

## 接口

`/api/v1` 不改。不按 Referer 或其他来源拒绝请求，不增加 403 规则。电脑网页和小程序的调用方式、路径、字段和状态码与下线前一致。

## 明确不变

- `GET/POST /api/v1/...` 的状态码和正文与下线前一致。
- 不删除、不改写数据库中的账号、账本、成员、明细、预算、计划、分享邀请和微信绑定。
- 不提供新的手机浏览器地址来替代 `/mobile/`。
