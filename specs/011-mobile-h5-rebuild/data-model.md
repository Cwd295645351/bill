# Data Model: 011-mobile-h5-rebuild

本特性**不新增、不修改**数据库表或列。下列实体描述 H5 客户端必须正确理解的现网概念（与 PC / 小程序同一套后端）。

## 用户账号（users）

| 概念 | 说明 |
|------|------|
| 登录标识 | 用户名 + 密码（传输前 RSA 加密）；H5 无注册写路径 |
| 会话 | `accessToken` / `refreshToken` / `expiresIn` + `userInfo`；失效后须重新登录 |
| 展示 | 「我的」展示昵称等；无微信头像/绑定状态 UI |

关系：同一账号在 PC、H5、（绑定后的）小程序共享账本成员关系。

## 账本（bills）与成员

| 概念 | 说明 |
|------|------|
| 账本列表 | 当前用户有权限的账本；无权账本不可见 |
| 空状态 | 不属于任何账本时列表为空说明，非报错 |
| 邀请加入 | 已登录用户凭邀请码 `POST /bill/join` 加入；无效码失败且不产生错误成员 |

## 账单记录（transactions）

| 概念 | 说明 |
|------|------|
| 类型 | 支出 / 收入；规则与用户手册一致 |
| 归属 | 支出可「全部」或多成员；收入仅单成员 |
| 创建者 | 系统记录；仅创建者可编辑/删除自己的明细 |
| 搜索 | 按关键字在账本内检索；无匹配为空状态 |

## 会话（客户端）

| 状态 | 行为 |
|------|------|
| 未登录 | 仅登录（及引导登录后的加入）可访问；业务深链重定向登录 |
| 已登录有效 | Tab 与业务页可用 |
| 失效 | 清本地令牌，回登录；不展示过期会话数据 |

## 明确不建模（首期）

- 微信 `user_wechats` 绑定关系（H5 不读不写）
- 资产、预算、计划、AI 等 PC 侧重实体
