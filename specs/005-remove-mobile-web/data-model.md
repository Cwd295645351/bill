# Data Model: 移除手机端网页

本次不新增、不修改、不删除任何持久化数据。下表只说明现有对象在下线后的状态，供验收时对照。

## 不变量

- 不执行 SQL，不调整 `sequelize.sync()` 的模型。
- 不注销账号，不解除微信绑定，不移除账本成员，不删除收支明细、预算、计划或分享邀请。
- 记账人、归属人、分享码有效期、谁可以删除账本，判断方式与下线前相同。

## 实体

### 账号

登录身份，电脑网页和小程序继续使用。

- 下线不新建、不删除账号。
- 电脑网页的登录态不因 `/mobile/` 关停而失效。
- 小程序的微信绑定保留，打开后仍按原方式自动登录。

### 账本与成员

联合记账的隔离单位，以及其中的人。

- 成员是否还在账本里，与当初从手机网页、电脑网页还是小程序加入无关。
- 下线不改成员名单，不要求重新加入。

### 收支明细

账本中的支出和收入。

- 无论从哪一端录入，仍属于原账本。
- 仍只有记账人可以编辑或删除自己的明细。这条规则由现有服务端判断完成，本次不改代码。

### 手机记账网页

已退出的客户端，不是数据库实体。

- 状态：下线。
- 没有单独的账务数据需要迁移。
- 入口行为见 [contracts/mobile-shutdown.md](./contracts/mobile-shutdown.md)。

## 状态

| 对象 | 下线前 | 下线后 |
|------|--------|--------|
| `/mobile/` 静态站点 | 可登录、查看、删除、加入账本 | 不存在 |
| 账号、账本、明细、预算、计划、绑定 | 保留 | 保留，内容不变 |
| 电脑网页、小程序 | 可用 | 可用，能力不变 |
