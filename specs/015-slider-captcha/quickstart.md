# Quickstart: 015-slider-captcha

## 前提

- Redis 与现网 session 相同配置可用。
- 后端已包含 `GET /api/v1/common/captcha`，且 JWT unless / 前端 EXCLUDE 已放行该路径。
- 若跑 `server/dist`，需使用含 captcha 的构建产物并重启进程。

## 验证拉题（公开）

未登录请求 `GET /api/v1/common/captcha`，应返回 `captchaId` 与图片字段，**不应**要求登录或弹出「请重新登录」。

## 验证 PC

1. 打开 `/pc/` 登录页：表单上**默认不出现**滑块。
2. 填好账号密码后点登录 → 弹出「安全验证」滑块。
3. 未对准或关闭弹窗 → 不完成登录。
4. 拖到对齐后用正确账号登录 → 成功。
5. 注册页同样：点「注册」后弹窗过滑块。

## 验证 H5

打开 `/mobile/` 登录，重复「点登录后弹窗；未滑失败 / 对准后成功」。

## 验证小程序

绑定页点绑定后弹窗过滑块；已绑定账号静默进入**无**滑块。

## 验证一次性

抓包复用同一 `captchaId` 第二次提交 login → 应失败。

> UI：滑块不在登录/注册/绑定表单默认展示；点击提交后弹窗出现，前端按 `targetX`/`tolerance` 校验位置，错位失败并刷新。
