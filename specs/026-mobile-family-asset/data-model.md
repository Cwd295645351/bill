# 数据模型：移动端家庭资产

**功能分支**: `026-mobile-family-asset` | **日期**: 2026-11-21

不新增表，不改现有字段含义。手机读写的仍是电脑端已经在用的资产数据。

## 资产

一笔钱或一笔债，属于一个账本和一名资产成员。

| 字段 | 规则 |
|------|------|
| 名称 | 必填，保存后可改 |
| 资产成员 | 必填，必须是本账本未隐藏的资产成员 |
| 资产类型 | 流动资金、固定资产、投资理财、应收款、负债之一 |
| 四笔钱 | 非负债必填：活钱、稳健、长期、保险。负债不保存四笔钱 |
| 币种 | 人民币、港币、美元，默认人民币。保存后不能改 |
| 当前金额 | 不小于 0，不能空。编辑时只有数值变化才新增盘点 |
| 渠道、周转周期 | 手机不展示。新建用服务端缺省。编辑必须送回原值 |
| 险种、年交保费 | 仅四笔钱为保险时保留。年交保费不小于 0。改离保险后清空 |

删除资产时，该笔和它的盘点不再出现在列表和统计中。

## 盘点

某一天的原币金额，属于一笔资产。

| 规则 | 说明 |
|------|------|
| 当前金额 | 日期最新的一条。同一天多条以最后保存的为准 |
| 上一次盘点 | 日期更早的最近一条。只有一条时，该笔变化为没有变化 |
| 新增 | 金额不小于 0，日期必填，成为新的一条 |
| 修改 | 改的是选中的这一条，不另起一条 |
| 删除 | 只剩一条时不能删 |
| 编辑资料引起的新增 | 仅当当前金额变化。日期为保存当时，旧记录不变 |

手机列表按日期从新到旧，每页 10 条。

## 资产成员

只有名字，和记账成员不是同一份名单。

| 状态 | 行为 |
|------|------|
| 未隐藏 | 出现在筛选和登记名单里 |
| 已隐藏 | 软删除。名字离开可选名单。名下资产仍在，并出现在「全部」里，家庭合计不变。手机不单列、不恢复 |
| 改名 | 名下资产和该成员自己的养老计划一起改名，金额不变 |
| 新增 | 可以没有登录账号。与当前未隐藏成员同名时不能再添加 |

## 汇率

每个账本一套港币、美元对人民币的汇率。必须大于 0。未保存过时展示大于 0 的初始值并说明正在使用。修改后人民币汇总和历史月份按新汇率重算，原币盘点和条数不变。

## 对比日

只用于总览卡片上的总变化，不用于每一笔涨跌。默认是当前筛选的上一个盘点日，不得晚于今天，不得改用上一个自然月末。截至该日的金额取该日及以前最新一条盘点；没有则按 0。没有更早盘点日时，卡片变化为没有变化。

本次查看内可以改对比日。离开资产或换账本后回到默认。

## 养老计划

「全部」或某一名未隐藏资产成员各一份。包含目标金额、开始月份和可选目标月份。目标金额必须大于 0。开始月份不得晚于本月。目标月份可以不填；填写时必须晚于本月。

推算只读记账：收入和支出可分别取近 3 年或近 5 年，默认近 3 年。默认剔除没有收入的月份，且只影响收入平均。不写回记账，不计投资收益和通胀。隐藏后不能再选中该成员，因此不能打开他的计划。

## 年度收支对账

不另存结果。某一年的记账合计与同期资产变化，读取记账、已保存的概览规则和盘点。

| 项 | 规则 |
|----|------|
| 年份 | 有记账的年份。默认今年。今年统计到本月，已结束年份到 12 月 |
| 全部 | 每一笔收入、每一笔支出各算一次 |
| 单人 | 收入只算同名记账成员。支出含只归属他的金额，以及按有效收入拆给他的共同支出和公共支出 |
| 对不上名字 | 收入和支出为 0，并说明没有找到同名记账成员。资产变化仍按他的资产算 |
| 总资产变化 | 期末减期初。期初优先上一年 12 月底；没有则改用本年第一个有数的月底 |
| 差额 | 总资产变化减收支结余。绝对值小于 0.01 元为相等，否则不相等。缺少盘点时总资产变化和差额为空 |
| 开关 | 不受「移除固定资产」影响 |

## 本次查看状态

不入库。

| 状态 | 范围 |
|------|------|
| 成员筛选 | 只有「全部」和未隐藏成员。总览、四笔钱、月历、趋势、养老和对账之间保持。换账本、或正在看的成员被隐藏后，回到「全部」 |
| 移除固定资产 | 只改总览卡片上的总资产和净资产。离开资产或换账本后关闭 |
| 隐藏金额 | 只遮显示。离开资产或换账本后关闭 |
| 手选对比日 | 只影响卡片总变化。离开资产或换账本后回到默认 |
| 对账年份 | 本次查看内保持。离开资产或换账本后回到默认年份 |
