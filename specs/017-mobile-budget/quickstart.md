# Quickstart: 017-mobile-budget

## 前提

- 后端可访问；至少有一个测试账本，当前自然年可准备「有预算 / 无预算」两种状态。
- mobile-h5 可打开 `/mobile/`；微信开发者工具打开 `miniapp/`（已构建 npm）。
- 接口摘要见 [contracts/budget-api.md](./contracts/budget-api.md)；模型见 [data-model.md](./data-model.md)。
- 可选：同一账本在 PC 预算页可对照金额与花费。

## 1. 查看当年预算（P1 / SC-001）

**小程序与 H5 各做一遍。**

1. 登录 → 进入测试账本。
2. 确认账本内底栏五入口可见；当前在「记账」时切换到「预算」。
3. 有数据时期望：标题「预算」、展示当前年、年度预算/年度支出、占比饼图、类型卡片（左类型右状态；预算与花费同行；进度条）。
4. 无数据时期望：空态「今年还没有预算」、无饼图、仍有「新增预算」。
5. 点「概览」「计划」「资产」：进入对应未交付占位页并提示到电脑端；入口不置灰不消失。

耗时目标：有数据账本，正常网络下约 30 秒内看清某类型进度。

## 2. 新增 → 编辑 → 删除（P1 / SC-002）

**两端各完整走通。**

1. 新增：选未占用可见支出类型，金额 > 0 → 保存 → 卡片出现，花费为当年已有支出（可为 0），汇总/饼图更新。
2. 负例：不选类型或金额 ≤ 0 → 不保存并提示；已占用类型不出现在可选列表。
3. 编辑：改金额，类型只读 → 保存后进度更新。
4. 删除：确认后条目消失，该类型历史记账仍在；取消确认则仍在。

## 3. 下钻搜索（P2 / SC-004）

1. 准备：某类型当年有支出、且已设预算。
2. 点该卡片空白处（避开编辑/删除）。
3. 期望：进入搜索页；支出 + 该类型 + 当年起止已预填；**无需再点搜索**即列出匹配流水。
4. 另测无支出类型：自动搜索后为空态文案，不伪造数据。
5. 返回：能回到预算或账本上下文，账本未丢。

## 4. 多端一致（P2 / SC-003）

1. PC 为账本新增/修改一条当年预算。
2. 小程序与 H5 打开预算页：金额、花费与 PC 一致。
3. 在 H5（或小程序）改金额或删除 → 另一移动端与 PC 刷新后一致。
