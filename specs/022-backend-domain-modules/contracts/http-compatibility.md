# 契约：现有接口保持兼容

**功能分支**: `022-backend-domain-modules` | **日期**: 2026-11-17

电脑网页、手机网页和微信小程序继续请求同一套地址。本期不改这三端。

## 地址与方法

前缀保持 `/api/v1`。下列分组的路径和方法保持不变：

| 分组 | 前缀 |
|------|------|
| 登录与账号 | `/api/v1/common` |
| 账本 | `/api/v1/bill` |
| 类型与概览规则 | `/api/v1/billtype` |
| 预算 | `/api/v1/budget` |
| 计划 | `/api/v1/plan` |
| 记账 | `/api/v1/transaction` |
| 概览 | `/api/v1/overview` |
| 家庭资产 | `/api/v1/asset` |
| 智能解析 | `/api/v1/ai` |

未登录放行名单保持现在这些地址：登录、登出、登录配置、滑块、注册、微信登录、微信绑定、微信注册，以及照片和头像的签名读取。

## 成功响应

成功时字段仍是 `retCode`、`message`、`data`。成功的 `retCode` 为 0。不得删除已有成功字段，不得要求用户重新注册或更换地址。

登录、注册、滑块和微信绑定成功后，结果里仍能取出现在的访问凭证、刷新凭证、有效时长和用户资料。

业务失败仍用同一组字段，`retCode` 为 1，`message` 为中文说明。说明原文见 [bill-access.md](./bill-access.md)。

## 用错方法

已经存在的地址如果用了不允许的方法，必须表现为方法不对，而不是没有这个地址。每个分组用自己的允许方法，不得把别的分组的允许方法套过来。

## 明确不改

- 金额算法、概览和月汇总的计算方式。
- 归属人「全部 / 单人 / 多人」的存法。
- 跨站访问策略、会话签名密钥、环境变量名单。
- 历史规格目录，包括 `specs/004-multi-belong-users/`。
