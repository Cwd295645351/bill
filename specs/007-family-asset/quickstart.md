# Quickstart: 家庭资产

手工验收。仓库的 `npm test` 仍是占位，本次不新增测试框架。预期口径以 [spec.md](./spec.md) 为准，字段以 [contracts/asset-api.md](./contracts/asset-api.md) 为准。

## 准备

1. 在仓库根目录执行 `npm run dev`，同时启动电脑网页和服务端。
2. 用已有账号登录电脑网页，进入一个自己是成员的账本。
3. 顶栏应出现「资产」。记账、概览、预算、计划仍在，打开后的原有页面不被这次改动换成资产页。
4. 准备另一个不是该账本成员的账号，后面用来确认看不到这里的资产。

下面用这个账本里的新数据验收，不要依赖原型里的示例金额。

## 1. 成员和登记

1. 打开资产，新增资产成员「甲」。名单里出现甲，不要求甲有登录账号。
2. 登记一笔：名称「工资卡」，成员甲，资产类型流动资金，四笔钱活钱，当前金额 100。
3. 总资产为 100，总负债为 0，净资产为 100。列表里有工资卡，盘点只有 1 条，日期是今天。
4. 四笔钱选活钱、稳健或长期时，表单不出现险种和年交保费。改成保险后，这两项出现。
5. 把工资卡改成保险并填写险种，保存后再改回活钱并保存。再次编辑时不再出现原先的险种。
6. 金额留空或填 0 时保存失败，列表笔数不变。

## 2. 负债和只改名称

1. 再登记「房贷」，成员甲，资产类型负债，金额 40。类型为负债时不出现四笔钱。
2. 总资产仍是 100，总负债是 40，净资产是 60。四笔钱的卡片里看不到房贷，总资产也不含它。
3. 只把工资卡改名为「工资卡甲」，保存。盘点仍是 1 条。
4. 把工资卡金额改为 130 并保存。盘点变为 2 条，当前金额 130，上一次是 100。总资产 130，净资产 90。

## 3. 改正历史盘点

1. 打开工资卡的盘点，修改较早那条的金额，不改它的日期。保存后当前金额仍是较新那条。
2. 把较早那条的日期改到比另一条更新，保存。当前金额改为这一条。
3. 打开房贷。只有 1 条盘点时，删除不可用，修改可用。
4. 打开修改后不保存就关闭，金额和日期与打开前相同。

## 4. 隐藏成员

1. 隐藏成员甲。名单里不再有甲。
2. 工资卡和房贷仍在，净资产与隐藏前相同。

## 5. 筛选、上月末、构成、月历、趋势

1. 再新增成员「乙」和一笔乙的非负债资产。成员选乙时，总览、四笔钱、构成、月历、趋势都不再出现甲的资产。选全部后恢复家庭合计。
2. 总览写明对比日是上一个自然月的最后一天。在非负债金额不变时，只增加负债，总资产变化不变。
3. 构成从左到右是净资产与负债、总资产、四类非负债、每一笔非负债资产。房贷只出现在左侧。类型名是「固定资产」而不是「固定资金」。切到比例时，净资产份额与负债份额之和为 100%。隐藏金额后仍能看到名称；成员为全部时能看到归属。
4. 月历默认今年，柱只到本月。选一个已结束的年份时有 12 个月，并标出 12 月。任选一个有数的月份，总资产等于该月非负债之和，总净资产等于总资产减总负债。
5. 趋势「今年」画到本月，图铺满剩余高度。近 1 年、近 3 年、近 5 年分别覆盖 12、36、60 个月，并且都结束在本月。全部口径中流动资金、投资理财、固定资产、应收款向上堆叠，负债为负数。净资产只有一层。自定义的结束日期晚于本月时，只画到本月。开始日期晚于结束日期时不画，并说明原因。
6. 月历每类显示「较年初」。今年 1 月没有盘点时，较年初等于所看月份的金额。
7. 总览打开「排除固定资产」后，固定资产不再计入当时的总资产和净资产，总负债不变。每个类型下先看到成员小计。
8. 四笔钱里活钱、稳健、长期的比例加起来是 100%，明细按成员分组。

## 6. 别的账本和其他端

1. 换到另一个账本，看不到上一账本的成员和资产。
2. 用不是这个账本成员的账号请求该账本的资产，请求失败，响应里没有这些资产。
3. 微信小程序里没有新的资产入口。记账、概览、预算、计划的原有操作仍按原来的方式完成。
4. 打开 `docs/用户手册.md`，目录里有「PC 端：家庭资产」。能读到总资产不含负债、隐藏成员不删除资产、只剩一条盘点不能删除，以及小程序不能管理资产。
